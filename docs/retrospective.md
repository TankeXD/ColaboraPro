# Retrospectiva de cierre (registro de análisis)

> Registro de análisis elaborado a partir del informe EPE1 y los datos del backlog. No representa una reunión presencial ni participación externa confirmada.

## Start
- Ejecutar pruebas automatizadas antes de declarar una historia como terminada.
- Refinar historias con criterios de aceptación medibles.
- Mantener el repositorio y el tablero vinculados.

## Stop
- Dar por implementado un ítem basándose solo en el estado del tablero.
- Comprometer historias con dependencias externas poco evaluadas.

## Continue
- Usar feedback para ajustar el backlog.
- Contar solo puntos que cumplan la Definition of Done.

## Acciones
1. Crear base de código, tests y CI.
2. Revisar criterios de aceptación y limitaciones en README.
3. Separar indicadores simulados del historial verificable.
